# 🚗 CarAssembly Game

CarAssembly — это игра, в которой игрок создаёт запчасти, собирает автомобили и продаёт их. Сборка требует деталей разных типов и уровней, а также системы прокачки и торговли.

## 🎮 Геймплей

> Игрок фармит металлолом, крафтит запчасти (двигатель, трансмиссия, электроника и т.д.), и собирает из них автомобили. Затем он может продавать автомобили или оставлять их для коллекции.

## 🔧 Как собрать машину

Чтобы собрать машину:

Собери все 7 частей одного уровня

Нажми кнопку "Собрать" в подойдя к серой машине на заднем дворе

Машина появится на парковке (если место есть)



## 📁 Структура проекта:

├── Scripts/Systems/            # Логика инвентаря, создания частей
├── Scripts/Player/             # Управление персонажем и анимацией
├── Scripts/UI/             	 # Скрипты для интерфейса
├── Prefabs/                    # Префабы деталей, машин, игрока и интерфейса
├── Scenes/                     # Сцены: гараж, магазин, парковка
└── Art/                        # 3D-модели и текстуры
└── ExternalAssets/             # Разного рада визуальные ассеты
